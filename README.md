# Linear-Regression
A from-scratch implementation of Linear Regression in Python, built without machine learning libraries like sklearn.

## Background
This project was originally developed as an assignment for the **Pattern Recognization** course at **National Yang Ming Chiao Tung University (NYCU)** during the Spring 2024 semester.

This project provides a clean, object-oriented implementation of linear regression, featuring both Closed-form Solution (Normal Equation) and Gradient Descent optimization methods, complete with feature scaling and evaluation metrics.
